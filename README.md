# My Fitness Repository — iPhone PWA

Upload all four files to the root of a GitHub Pages repository:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Then open the GitHub Pages URL in Safari and use Share -> Add to Home Screen.

Data is stored locally in the browser on the user's device. The GitHub Pages source is public if using GitHub Free.
